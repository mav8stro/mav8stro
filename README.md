## Flagship — E-Patient

An **AI-assisted pre-consultation healthcare portal** that aggregates doctors from multiple hospitals into a single platform — built to serve patients, doctors, and hospital administrators at once.

```mermaid
flowchart TB
    subgraph Users[User Layer]
        PAT[Patient]
        DOC[Doctor]
        ADM[Hospital Admin]
    end

    subgraph Core[E-Patient Platform]
        UI[Web Portal]
        API[API Layer]
        AI[AI Pre-Consultation Engine]
        DB[(Aggregated Hospital Data)]
    end

    PAT --> UI
    DOC --> UI
    ADM --> UI
    UI --> API
    API --> AI
    API --> DB
    AI --> DB

    style Users fill:#0E1512,stroke:#2BB6A3,color:#EDEDE6
    style Core fill:#132420,stroke:#B5651D,color:#EDEDE6
    style AI fill:#B5651D,stroke:#B5651D,color:#0E1512
    style DB fill:#2BB6A3,stroke:#2BB6A3,color:#0E1512
```

One portal, three user types, one AI layer handling pre-consultation intake — so hospitals stop making patients repeat themselves across systems.
